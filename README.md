# 日本語版ELIZA — ルールベースの対話を体験するWebアプリ

G検定の学習で知ったELIZAを、日本語で体験するための学習作品です。
入力された文章に対して、キーワードやパターンに対応する応答を返します。

**大規模言語モデルを使わず、ルールの組み合わせで会話らしいやりとりを作る仕組み**
を確認できます。

## できること

- ブラウザ上で日本語のメッセージを入力する
- ルールベースの応答と会話履歴を表示する
- 「さようなら」などの終了語でセッションを終える
- ターミナル風の画面と入力中の演出で対話を体験する

## 起動方法

[eliza-jp.html](eliza-jp.html) をダウンロードし、ブラウザで開いてください。
ビルド、パッケージのインストール、APIキーは不要です。

GitとPython 3を使う場合は、次の方法でも起動できます。

```bash
git clone https://github.com/GitTarochan/-Eliza.git
cd ./-Eliza
python3 -m http.server 8000
```

[http://localhost:8000/eliza-jp.html](http://localhost:8000/eliza-jp.html) を開きます。
新しい会話を始める場合はページを再読み込みしてください。

## 使用技術と仕組み

| 項目 | 実装 |
|---|---|
| 画面 | HTML、CSS |
| 対話処理 | JavaScript |
| 応答選択 | キーワード・正規表現・応答テンプレート |
| ファイル構成 | 画面、ルール、対話エンジンをeliza-jp.htmlに収録 |

日本語のパターン照合では、英語向けの単語境界をそのまま使わない処理が含まれます。
応答処理はブラウザ内で動作し、外部の生成AI APIを呼び出しません。

## この作品で確認できること

入力に応じた応答ルールと、日本語のチャット画面を組み合わせた実装です。
応答が自然に見える場合と、ルールの限界が表れる場合を比較できます。
会話品質の定量評価やユーザーテスト結果は掲載していません。

## 制約

- 応答は事前に定義したルールに基づき、文章の意味を広く理解するものではありません。
- 言い回しや表記によっては、意図に合わない返答になる場合があります。
- 会話の自然さや一貫性を保証するものではありません。
- 心理相談や診断を目的としたアプリではありません。
